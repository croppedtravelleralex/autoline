# 本地开发指南

本指南将帮助您在本地环境搭建、启动并联调 AutoLine 系统，无需每次更新都推送到 GitHub/Zeabur。

## 1. 环境准备

### 后端 (Python - Conda)
- **Conda 环境**: 使用您已有的 `cursor` 环境。
- **步骤**:
  1. 系统中需已安装并配置好 Conda。
  2. 脚本会自动执行 `conda activate cursor`。
  3. (初次使用或依赖更新时) 请确保在 `cursor` 环境中安装了依赖：`pip install -r backend/requirements.txt`。

### 前端 (Node.js)
- **Node.js 版本**: 18 或更高
- **步骤**:
  1. 打开终端，进入 `frontend` 目录。
  2. 安装依赖: `npm install`

## 2. 本地启动服务

### 快速启动 (推荐)
在项目根目录下，直接双击运行 [start-dev.bat](file:///C:/Users/Lenovo/Desktop/program/autoline/start-dev.bat)。该脚本会在同一个窗口中启动前后端，**关闭窗口即自动停止所有服务**。

### 手动启动
1. **启动后端**:
   - 进入 `backend` 目录，确保虚拟环境已激活。
   - 运行 `python main.py`。
   - 后端默认运行在 `http://localhost:8080`。

2. **启动前端**:
   - 进入 `frontend` 目录。
   - 运行 `npm run dev`。
   - 前端默认访问地址为 `http://localhost:5173`。

## 3. 本地联调说明
- 我们已经在本地前端配置了 **Vite 代理 (Proxy)**，它会自动将所有的 `/api` 请求转发到本地的 `8080` 端口。
- 您在本地开发时，直接访问前端 `5173` 端口即可，系统会像在 Zeabur 上一样正常工作。

## 4. 更新与推送流程
1. **本地修改**: 在本地进行代码修改。
2. **本地测试**: 运行本地服务，观察功能是否正确。
3. **记录更新**: 在 [docs/更新日志.md](file:///C:/Users/Lenovo/Desktop/program/autoline/docs/更新日志.md) 中记录本次更新的功能或修复。
4. **批量推送**: 当完成了若干个更新并通过测试后，再执行 `git push` 同步到 GitHub，触发布署。
