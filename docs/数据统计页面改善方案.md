# 数据统计页面改善方案

> 文档版本: 1.0  
> 创建日期: 2026-02-01  
> 目的: 分析现有数据统计模块不足，提出符合工业MES软件标准的改善建议

---

## 一、现状分析

### 1.1 当前页面结构

| 组件 | 功能 | 问题 |
|------|------|------|
| `MESDataTable` | 实时显示小车当前MES参数 | 仅展示当前状态，无历史数据 |
| `MESHistoryChart` | 按腔体查询温度/真空度曲线 | 仅限腔体维度，无小车工艺追溯 |

### 1.2 主要不足

> [!CAUTION]
> 当前页面**不符合工业软件标准**，缺失关键生产追溯功能

1. **无工艺历史记录** - 无法查看小车在各工位的历史工艺数据
2. **缺少时间维度** - 未显示工艺开始时间、结束时间、持续时长
3. **无工艺时间轴** - 无法直观展示小车完整工艺流程
4. **数据导出缺失** - 无法导出报表用于质量追溯
5. **筛选功能弱** - 无法按批次号、日期范围、工艺类型筛选


## 三、改善方案

### 3.1 新增功能模块

```
数据统计页面 (Statistics.tsx)
├── 📊 实时数据表 (MESDataTable) -- 保留并增强
├── 📈 历史趋势图 (MESHistoryChart) -- 保留
├── 🆕 小车工艺历史 (CartProcessHistory) -- 新增
├── 🆕 工艺时间轴 (ProcessTimeline) -- 新增
└── 🆕 数据导出面板 (DataExportPanel) -- 新增
```

### 3.2 新增组件详细设计

#### 3.2.1 小车工艺历史表 (CartProcessHistory)

**功能**: 查询并展示指定小车的完整工艺历史记录

| 列名 | 说明 | 示例 |
|------|------|------|
| 小车编号 | 唯一标识 | A-001 |
| 工艺名称 | 当前执行工艺 | 电子刷洗 |
| 工位/腔体 | 执行位置 | A-Scrub |
| 开始时间 | ISO格式时间 | 2026-02-01 09:15:00 |
| 结束时间 | ISO格式时间 | 2026-02-01 11:30:00 |
| 持续时长 | 计算值 | 2h 15m |
| 结果状态 | 完成/异常/进行中 | ✓ 完成 |
| 批次号 | 追溯标识 | BATCH-260201-A |

**筛选条件**:
- 小车编号 (单选/多选)
- 日期范围 (开始日期 - 结束日期)
- 工艺类型 (烘烤/刷洗/激活/铟封等)
- 结果状态 (全部/完成/异常)

#### 3.2.2 工艺时间轴 (ProcessTimeline)

**功能**: 甘特图形式展示小车工艺流程

```
时间轴示意：
┌────────────────────────────────────────────────────────┐
│ A-001  [进样]──[烘烤]────────[刷洗]──[待机]──[铟封]──   │
│ A-002     [进样]──[烘烤]────────────────[刷洗]───       │
│ C-001        [进样]──[烘烤]────[激活]──────────[生长]─  │
├────────────────────────────────────────────────────────┤
│         08:00   09:00   10:00   11:00   12:00          │
└────────────────────────────────────────────────────────┘
```

**交互功能**:
- 鼠标悬停显示工艺详情（温度、真空度、时长等）
- 点击工艺块跳转到详细记录
- 时间轴缩放（1小时/6小时/12小时/24小时/自定义）
- 颜色编码区分工艺状态（绿色=正常，黄色=延迟，红色=异常）

#### 3.2.3 数据导出面板 (DataExportPanel)

**功能**: 导出MES数据用于质量追溯和报表

| 导出格式 | 内容 | 用途 |
|----------|------|------|
| CSV | 工艺历史明细 | Excel分析 |
| PDF | 单批次追溯报告 | 质量审计 |
| JSON | 原始数据 | 系统集成 |

## 四、后端API需求

### 4.1 现有API (可直接使用)

| API端点 | 功能 | 备注 |
|---------|------|------|
| `GET /history/{entity_id}` | 查询实体历史数据 | 支持时间范围 |
| `GET /history/snapshots/range` | 获取快照时间范围 | - |
| `GET /history/events` | 获取系统事件 | 用于时间轴标记 |

### 4.2 需要新增的API

```python
# 建议新增接口

# 1. 获取小车工艺历史
GET /api/cart/{cart_id}/process-history
Query: start_time, end_time
Response: [{ step_name, start_time, end_time, chamber_id, status, params }]

# 2. 批量获取多辆小车工艺时间轴
GET /api/carts/timeline
Query: cart_ids[], start_time, end_time
Response: { cart_id: [{ step_name, start, end, color }] }

# 3. 导出MES报表
GET /api/export/mes-report
Query: type=csv|pdf|json, cart_ids[], date_range
Response: file download
```

## 七、总结

当前数据统计页面功能简陋，不满足工业MES软件对**生产追溯**和**质量分析**的基本需求。建议按照本文档方案进行改进，重点补充：

1. ✅ **小车工艺历史查询** - 支持按时间/批次筛选
2. ✅ **工艺时间轴可视化** - 甘特图直观展示
3. ✅ **数据导出功能** - 支持CSV/PDF格式

实施后将大幅提升系统的数据分析和质量追溯能力，符合工业4.0标准。
